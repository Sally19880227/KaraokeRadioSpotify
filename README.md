# Karaoke Radio — 動画非表示・カラオケ専用プレイヤー

YouTube上の音楽を、**動画は一切表示せず**、カラオケ風の歌詞だけを大きく表示しながら聴けるツールです。
曲名・アーティストで検索して1曲選ぶと、以降は同じアーティストの曲を自動的に検索して次々に流し続けます。

## できること

- 🔍 **検索**: 曲名・アーティスト名でYouTube上の楽曲を検索（音楽カテゴリに絞り込み）
- 🎤 **カラオケ表示**: 現在歌っている行を画面いっぱいに大きく表示、次の行も表示
- 🔁 **自動選曲**: 1曲終わると、同じアーティストの別の曲を自動検索して流し続ける（延々と続きます）
- ▶️ **自動再生**: 曲が終わったら自動的に次の曲へ
- 🙈 **動画非表示**: 映像は画面に表示されません（音声とカラオケ歌詞のみ）
- ⏭ **スキップ**: 今の曲を飛ばして次のアーティスト曲へ
- ⏱ **歌詞のズレ調整**: スライダーおよび±0.2秒ボタンで歌詞タイミングを補正
- 🕘 **検索履歴**: 過去に検索した語句をワンタップで再検索

## 使い方

1. 右上の⚙からYouTube Data APIキーを設定（RyoTubeで使っているものと同じキーを使い回せます）
2. 上部の検索欄で曲名・アーティスト名を検索
3. 結果一覧から曲をタップ → カラオケ画面に切り替わり再生開始
4. 曲が終わると自動的に同じアーティストの別の曲が流れ続けます
5. 「⏭」ボタンで手動スキップ、「🔍 検索に戻る」で別の曲を検索し直せます

## 歌詞・自動選曲の仕組みについて

- 歌詞は [LRCLIB](https://lrclib.net/)（無料・無認証の歌詞データベース）を、再生中の動画タイトルから推測した曲名・アーティスト名で検索して取得しています。見つからない場合は歌詞なしで再生のみ続きます。
- 自動選曲は、再生中の曲のアーティスト名でYouTube検索を行い、その結果からランダムに1曲選んでいます。公式のYouTube Musicのおすすめ機能とは異なり、あくまで検索ベースの簡易的な仕組みです。
- **自動選曲・関連曲取得はYouTube Data APIのクォータを多く消費します**（1曲終わるごとに検索1回＝約100ユニット）。1日の上限に達するとその日は動作しなくなる場合があります。

## GitHubへのアップロード・公開手順

RyoTubeの時と同じ手順です。

1. GitHubで新しいリポジトリを作成（例: `KaraokeRadio`）
2. 空のリポジトリなら「uploading an existing file」、既存なら「Add file」→「Upload files」から
   `index.html` / `style.css` / `app.js` / `README.md` の4ファイルをアップロードしてCommit
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branchを `main` / `/(root)` にしてSave
4. 数分後、`https://あなたのユーザー名.github.io/リポジトリ名/` でアクセス可能になります
